# Getting started

This page takes you from nothing to a small book you have exported: a binder, a few scenes in order, some writing,
and a Word file at the end. It takes about ten minutes. Each step links to the page that covers it in full.

You need Binders installed and enabled. See [Installation](installation.md).

## 1. Make a binder

A binder is a folder whose notes and subfolders keep the order you give them.

To start a new one:

1. Right-click empty space in the file explorer and choose **New binder**. (Or run **New binder** from the command
   palette.)
2. A folder named "Untitled binder" appears with its name ready to type over. Call it after your book, say
   "The Lighthouse", and press Enter.

To use a folder you already have, right-click it and choose **Make this folder a binder**. Its notes and subfolders
keep the order they show in now, and none of them is changed.

The folder now says **binder** at the end of its row in the file explorer.

## 2. Open it

Click the binder in the file explorer. The binder view opens on it, as a corkboard: one index card for each note.
A new binder has no cards yet.

Opening a binder also puts two tabs in the right sidebar, **Inspector** and **Contents**. They are covered in
[The inspector and the contents](inspector.md); you don't need them yet.

## 3. Add scenes

1. Choose **New** in the binder view's toolbar, then **New note**. A card appears with its name ready to type.
2. Name it "Arrival" and press Enter.
3. Do it twice more: "The keeper" and "Storm warning".

Each card is an ordinary note in the binder's folder. You'll see all three in the file explorer too.

To say what a scene is about, click its card to select it, then click under its title and type a synopsis. Press
Ctrl+Enter (Cmd+Enter on macOS) to keep it, or Esc to leave it as it was.

## 4. Put them in order

Drag a card to where it belongs. A line shows where it will land, and the other cards move aside.

You can also drag the notes up and down in the file explorer. The corkboard and the file explorer always show the
same order, and each follows the other.

To group scenes into a chapter or a part:

1. Click the first card, then Shift-click the last, to select them.
2. Right-click one and choose **New folder from selection**.
3. Type the folder's name, such as "Part One".

The folder is now one card on the board. Double-click it to go inside, and use the breadcrumb above the board to
come back out.

More in [Corkboard](corkboard.md) and [Splitting, merging and grouping](splitting-and-merging.md).

## 5. Write

1. Click the button at the top left of the binder view, the one that says **Corkboard**, and choose
   **Manuscript**.
2. The whole binder is now one page: folder names as headings, each note's title above its text.
3. Click under a title and write.

Each section is the note itself in Obsidian's own editor, so what you type is saved to that note as Obsidian saves
any note. The arrow keys carry you from one scene into the next.

More in [Manuscript](manuscript.md). For writing with nothing else on the screen, see [Focus mode](focus-mode.md).

## 6. Keep track

Back on the corkboard, right-click a card:

- **Set status** marks how far along a scene is: Idea, Draft, Revised, Done.
- **Set label** gives it a color: a point of view, a storyline, whatever you want colors to mean.
- **Set target...** gives it a word count to reach.

More in [Labels, statuses and targets](labels-statuses-targets.md).

## 7. Export

1. Open the binder view's **More options** menu (the three dots in its header) and choose **Export...**.
2. On the left, choose what to make. **Manuscript** is a Word file in standard manuscript format.
3. If the window asks for **Your name**, type it. It is asked once and kept in Binders' settings.
4. The right side shows the text as it will read. Choose **Export**.
5. On a computer, your system's save dialog opens in a folder named `Exports` beside the binder. Choose where the
   file goes. On a phone or tablet the file goes into the `Exports` folder and then to the share sheet.

Your notes are not changed by exporting.

More in [Export](export.md).
