# The phone checklist

What the suite cannot give (ROADMAP.md, "A suite that can be trusted"): a short run by hand on the maintainer's iPhone
before each release, with the release's build. Emulation has missed bugs a real phone found, and a real keyboard,
suspension and the share sheet are not emulated at all. `npm run release` names this file before it asks.

Use a vault made for it (`npm run demo-vault`, synced to the phone), never a vault with real writing in it. About ten
minutes. Anything that goes wrong is written up as an issue before the release goes out, or the release waits.

## Install

- [ ] The build on the phone is this release's (BRAT, or the files copied in): Settings → Community plugins shows the
      version.

## Writing (the core of it)

- [ ] Open a binder from the file explorer. The corkboard, the outliner, the manuscript and the timeline each open.
- [ ] In the manuscript, tap into a section and type two sentences with the keyboard. The line being typed stays above
      the keyboard; the toolbar comes back when the keyboard goes.
- [ ] Switch to another app mid-sentence and come back (the app suspended). Nothing typed is lost, on screen or in the
      note opened by itself.
- [ ] Turn the phone on its side and back while typing. The caret and the text stay.
- [ ] Undo the last change from More options; Redo it.

## Order and notes

- [ ] Long-press a card and drag it to another place. Close and reopen the binder: the order holds.
- [ ] Make a new note from New; rename it from its menu. The file explorer shows it, in its place.
- [ ] Take a snapshot of a note, change a word, and bring the snapshot back. The word is as it was.

## Leaving and sharing

- [ ] The back gesture from a note opened from a card goes back to the binder, not out of Obsidian.
- [ ] Export the binder as an EPUB or a PDF and open it from the share sheet. It opens, with the book's text.

## Afterwards

- [ ] The note of a binder and its folder notes are as they were before (no property changed that nobody asked for):
      compare with the synced copy on the computer.
