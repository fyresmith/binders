<h1 align="center">Binders</h1>

<p align="center"><b>Ordered folders for long-form writing, inside Obsidian.</b><br>
A binder in the file explorer · a corkboard · a plot grid · the whole manuscript as one editable page</p>

> **In development.** Binders isn't ready to use yet. The plan is in [docs/plan.md](docs/plan.md).

Folders in Obsidian list their notes by name. Books don't work that way. Binders turns a folder into a **binder**: its
chapters and scenes keep the order you give them, right in Obsidian's file explorer. Open a binder to see it as:

- a **corkboard** of index cards you can drag into a new order;
- a **plot grid** of scenes against plotlines;
- a **manuscript**: every scene, in order, as one continuous page you can edit.

Everything stays plain Markdown: a binder is a folder plus one note that holds its order. See the
[file format](docs/file-format.md).
